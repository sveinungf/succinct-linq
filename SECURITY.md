# Security Policy

## Supported Versions

Only the latest available version of Succinct LINQ is supported for security updates.

## Reporting a Vulnerability

> [!IMPORTANT]
> Please do not open public GitHub issues, pull requests or discussions for anything you think might have a security implication.

To privately report a security vulnerability in Succinct LINQ, please create a security advisory in this [repository's Security tab][report-vulnerability].

> [!TIP]
> Further details on how to privately report a vulnerability using GitHub can be found in the [GitHub documentation][privately-reporting].
